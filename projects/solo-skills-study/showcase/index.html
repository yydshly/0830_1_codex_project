READ / 01
格式可迁移 ≠ 运行可迁移

复制一个 `SKILL.md` 很容易；让它在 Windows、Codex、不同账号和不同权限下可靠运行，才是我们的研究重点。

02 / MECHANICS 它为什么有效

它做的是上下文工程，不是训练一个新模型

Agent 先看到很小的能力目录，只有任务匹配时才加载完整规程；复杂知识和脚本继续按需展开。

DISCOVERY / ~100 TOKENS PER SKILL

只把名称和触发说明放进可见目录

Agent 不需要预先阅读全部 26 份长文。`name` 和 `description` 告诉它“会做什么、什么时候应该使用”。

输入
用户请求 + 技能目录
输出
最相关的候选技能
description: “会议转录 → 纪要 → 发布”

ACTIVATION / FULL SKILL.md

匹配之后，再把完整操作规程装进上下文

这里出现步骤顺序、输入输出、失败路径、审批要求和停止条件。它把“老手经验”变成模型可以遵循的临时制度。

输入
被选中的 SKILL.md
输出
可执行工作计划与边界
缺失转录 → 不得脑补 → 先请求副本

PROGRESSIVE DISCLOSURE / ON DEMAND

参考资料、模板和资产只在需要时读取

`references/` 保存细分规则和案例，`assets/` 保存模板。主文件保持可发现，深层知识又不会永久占据上下文。

输入
当前步骤所需资源
输出
模板、规则、基线或示例
references/ai-tell-taxonomy.md

EXECUTION / DETERMINISTIC WHERE POSSIBLE

判断交给 Agent，重复动作交给脚本或工具

PDF 转换、API 发布、SSH 卸载适合代码；内容判断、异常解释和取舍仍由 Agent 按规程处理。

输入
结构化参数与已授权动作
输出
文件、请求或外部状态变化
scripts/publish-thread.mjs --go

GOVERNANCE / HUMAN IN THE LOOP

真正的可靠性来自预览、审批、证据和恢复

高风险动作应当默认 dry-run、发布前复核、缺失信息停止、部分失败可恢复。仓库已经包含不少这种经验，但落实并不均匀。

输入
候选结果 + 风险状态
输出
批准、暂停、回滚或继续
status: HOLD / human review required
不是

新模型

没有再训练权重；价值来自按任务加载的过程知识。

不是

新权限

Skill 不能绕过宿主 Agent、操作系统或外部平台的授权。

不是

后台服务

定时与常驻依然需要 cron、launchd、队列或独立进程。

03 / USE CASES 使用场景 · 谁最值得用

重复三次、容易出错、又有明确边界的工作最适合

从三个采用视角切换。判断标准不是“能不能让 AI 做”，而是“能否把结果、风险和失败方式写成可验证规程”。

FIT / HIGH

ONE PERSON, MANY REPEATED FLOWS

把内容、客户沟通和日常运营变成“数字员工手册”

最适合反复发生、平台明确、仍需要人判断的任务，例如会议纪要、博客、产品演示和提醒。

直接价值
减少重新解释与重复踩坑
必要条件
保留人工审批与真实账号边界
先试技能
meeting-summary · web-demo-video
不应假设
复制文件后即可无人值守
FIT / HIGH

EVIDENCE → PROCEDURE → REUSE

把验证过的研究结论变成下一次实验自动遵循的规程

研究日志记录“为什么成立”，Skill 负责“下次如何做”。测试把结论从经验提升为可回归的能力。

直接价值
研究结论进入执行闭环
必要条件
每条规则链接证据和适用版本
先试技能
measured-ui-callouts · meeting-summary
不应假设
文档规则天然会被模型严格遵守
FIT / MEDIUM

RAW MATERIAL, NOT PRODUCTION PLATFORM

把个人 SOP 提炼成有权限、配置、评测和运行状态的组织能力

适合作为 Skill 工程的案例库，但必须先移除硬编码、补齐测试、幂等、秘密治理和客户端适配。

直接价值
丰富的失败案例与现实护栏
必要条件
能力清单、沙箱、审计与可观测性
先做工作
静态审计 · adapter · eval harness
不应假设
个人机器基线等于组织生产基线
✓

适合

步骤稳定、重复频繁、输入输出可说明、失败能被检测、外部动作可审批。

!

先加固

会发送、删除、付费、远程执行或处理秘密；必须有预览、权限和恢复。

×

不优先

一次性开放探索、目标无法验证，或要求强事务一致性的核心系统。
