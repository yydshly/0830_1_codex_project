# Artifacts

本目录保存理解 Solo Skills 研究结论所必需的小型验证报告。

- `baseline-verification.md`：锁定版本的身份、技能结构与随附代码基线。
- `showcase-capability-index.png`：1440px 八类结果能力总览，数量合计 26。
- `showcase-usage-desktop.png`：1440px 目标调用面板，展示可复制请求、四方职责与调用边界。
- `showcase-video-delivery.png`：1440px 真实媒体交付卡，展示播放器、规格与证据入口。
- `showcase-desktop.png`：1440px 明色、研究交付旗舰案例 5/5 READY 的完整网页证据。
- `showcase-tablet.png`：768px 深色、真实视频案例和播放器单栏布局的完整网页证据。
- `showcase-mobile.png`：390px 明色、真实视频案例和播放器纵向重排的完整网页证据。
- `showcase-browser-results.json`：七类目标调用、案例门禁、运行取消、键盘、主题、视口、错误与性能观察的结构化结果。
- `solo-skills-real-demo-contact-sheet.jpg`：真实视频首屏、筛选、机制、案例、5/5 与结束卡六个代表帧。
- `solo-skills-real-demo-evidence.json`：32 秒 MP4 的规格、浏览器状态检查点、媒体路径与错误记录。

不在此提交 Token、真实通信内容、第三方完整源码、依赖缓存或运行时生成的大型媒体文件。
