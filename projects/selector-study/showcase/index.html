能力 04 What it adds to copy

它给一次复制补上六类上下文。

普通模式压缩信息，Sharingan 模式补足复刻证据。两者解决的是不同成本的问题。

01

视觉目标

点击、多选、框选、父子与兄弟导航，把“这里”变成明确的 DOM 元素集合。

实现原理 05 Five-stage pipeline

从书签到 Prompt，只有五步。

  1. 01

    封装载荷

    构建器把 CSS 和源码片段编码进 javascript: 书签，安装后可离线启动。

    证据 ↗
  2. 02

    注入与监听

    遍历 Light DOM，写入临时 data-ai-id，在 capture 阶段监听事件，并用 MutationObserver 跟进 SPA。

    证据 ↗
  3. 03

    命中目标

    结合 elementsFromPoint()、可见性、交互标签与结构启发式决定用户真正指向的元素。

    证据 ↗
  4. 04

    组织上下文

    生成 selector、locator、语义容器与 React/Vue 信息；只有必要时才附加布局、HTML 和 props。

    证据 ↗
  5. 05

    交付给 Agent

    普通 prompt、Sharingan 报告、Markdown 或截图进入剪贴板；此后才是 Codex 的代码修改阶段。

    证据 ↗

Selector · 普通 Prompt

本地单个 UI 目标最适合使用紧凑上下文：身份和源码线索收益高，信息成本低。

  1. 01 · 收集selector、locator、组件链、instruction
  2. 02 · 补充目标页面路径与验收标准
  3. 03 · 交付交给 Codex 修改并人工审查 diff

可扩展方向 08 From clipboard to protocol

真正的下一步，是把一次复制变成闭环。

P0

结构化协议 / MCP

从自由文本升级为 JSON Schema，让元素、截图、源码位置和 instruction 可被 Agent 直接消费。

收益：减少解析歧义
P0

开发服务器源码映射

通过 Vite/Webpack/source map 稳定关联 DOM 与 JSX/Vue/Svelte 源码，不再依赖私有 debug 字段。

收益：生产级定位
P1

Shadow DOM 与 iframe

递归 open shadow root；对同源 iframe 注入，对跨域 frame 交给扩展或 CDP。

收益：扩大页面覆盖
P1

多状态采集

一次保存 hover、focus、active、disabled、暗色和多 viewport，而非只记录当前瞬间。

收益：减少视觉漏项
P0

隐私预览与策略

导出前显示字段清单，支持项目白名单、PII 检测和域名级策略。

收益：从启发式走向治理
P2

修改—验证闭环

Agent 修改后自动刷新、重新定位目标、截图 diff，并把结论固化为回归测试。

收益：从交接变成验证

对我们的意义 09 Adoption decision

工具值得用，根依赖不值得加，研究问题值得继续。

我们的仓库强调“问题 → 假设 → 实验 → 证据 → 结论”。Selector 的直接价值，是让一次复制不只有可见文本，还能带上元素身份、页面结构和框架线索，减少后续研究与修改时的指代歧义。

边界 09 Local does not mean harmless

本地运行，不等于可以盲目复制。

Sharingan 会观察页面运行态。真正的安全边界发生在“复制给谁、复制了什么”。

DOM

Shadow DOM / iframe

当前主要覆盖 Light DOM；没有通用 shadow root 与 frame 内遍历。

ORIGIN

跨域 CSS / 资源

免费书签版无法读取跨域 stylesheet 文本，也可能无法内联跨域图片与字体。

DEBUG

框架私有字段

React/Vue 组件与源码信息在开发构建最有效，不能保证跨版本稳定。

PRIVACY

启发式脱敏

报告可能包含 URL、表单值、props/state 和页面文本；导出前必须复核。

PAGE

页面侵入性

工具写入 data-ai-id 并拦截事件；结束后刷新页面是最干净的恢复方式。
