# 项目工作区

projects 目录用于容纳彼此独立的研究子项目。一个目录对应一个清晰的问题域，可以使用自己的语言、依赖管理、测试和部署方式。

## 新增项目

1. 复制 project-template，并用小写短横线命名新目录。
2. 修改 README.md 与 index.md 中的项目名。
3. 写清上游仓库、锁定版本、许可证和研究边界。
4. 定义成功标准与复现步骤后再开始实验。
5. 在根 README 的研究索引中登记项目。

如果被研究对象本身是另一个仓库，优先记录精确提交并通过依赖管理器拉取。只有确实需要修改其源码或保留完整历史时才使用 Git submodule；不要直接复制来源不明的源码。

## 项目最低要求

- README.md：问题、范围、实验矩阵、结果、复现方式和结论。
- index.md：Pages 展示入口，通常只需包含项目 README。
- research-log.md：按时间记录实验、失败和下一步。
- tests/：可自动验证的证据。
- artifacts/：必要的小型截图、样例数据或报告。

大型二进制文件、模型和数据集不应直接提交。请记录可校验的下载来源，并在项目 README 中说明获取方式。
